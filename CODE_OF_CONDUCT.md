# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
version 2.1 as its Code of Conduct.

In short: be respectful and constructive. Harassment and discrimination are not
tolerated.

## Reporting

If you experience or witness unacceptable behavior, please report it by opening a
confidential [security advisory](https://github.com/marble-sh/backstage-plugins-grafana/security/advisories/new)
or contacting the maintainers listed in [`.github/CODEOWNERS`](.github/CODEOWNERS).
All reports will be handled discreetly.
